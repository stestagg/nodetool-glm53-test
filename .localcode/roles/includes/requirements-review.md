## Requirements

When `.localcode/requirements.md` exists, it lists what the project has been
asked to do, each requirement with a `REQ-<n>` id. Check the work against it: a
requirement that bears on the work but is missed, one the work contradicts or
only partly meets, and a cited id that does not say what the work claims are
all review findings. A requirement that belongs to other work is not missing
from this, and nothing the document does not state is a requirement.
